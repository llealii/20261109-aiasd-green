## Task Manager (SL-001: capture and reopen a task)

Browser-only, local-first React + TypeScript app. Tasks are stored in IndexedDB (database `task-manager`, store `tasks`); there is no backend, account, or sharing.

- Supported environment (recorded choice): current desktop Chrome, Edge, Firefox, or Safari, using the same browser profile and the same origin (served by `npm run dev` at `http://localhost:5173` or `npm run preview` as a static build). Data does not carry across browsers, profiles, or origins.
- Commands: `npm install`, `npm run dev`, `npm test`, `npm run build`, `npm run lint`.
